# Processo de gestão de riscos de TI em BPMN

Dois processos que dão sequência ao diagnóstico de maturidade em gestão de riscos de TI:
depois de saber quais riscos estão sem tratamento, o órgão cria, implanta e monitora o plano de tratamento.

| Arquivo | Processo | Atividades |
|---|---|---|
| [`criar-plano-de-tratamento-dos-riscos.bpmn`](criar-plano-de-tratamento-dos-riscos.bpmn) | Criar Plano de Tratamento dos Riscos | definir contexto → identificar → analisar (probabilidade × impacto) → avaliar → criar o plano, com comunicação às partes interessadas |
| [`monitorar-e-implantar-plano-de-riscos.bpmn`](monitorar-e-implantar-plano-de-riscos.bpmn) | Monitorar e Implantar Plano de Riscos | monitorar ou implantar → executar o plano → análise crítica → atualizar o registro do risco, reabrindo o plano quando surgem riscos novos |

Cada tarefa traz a descrição do passo no campo de documentação do BPMN.

## Como abrir

- No navegador: [demo.bpmn.io](https://demo.bpmn.io), arrastando o arquivo para a página.
- No desktop: [Camunda Modeler](https://camunda.com/download/modeler/).
